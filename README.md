# FinLife 360

One consolidated personal-finance app that will combine the best features of CB's existing finance apps (finz-admin-pilot, finance-faqs, taxes-faqs, stocks-retire-faqs, intel-myben, home-admin-faqs, life-admin-pilot and others).

**Status:** audit complete, no application code yet. Implementation starts after the audit is approved.
